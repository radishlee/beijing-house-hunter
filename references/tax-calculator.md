# 含税系数表与预算反推（第 4 步必读）

## 一、含税系数（占裸价比重，估算用；精确值以个案核定为准）

| 房源状态 | 增值税 | 地价款 | 契税 | 个税 | **合计系数** |
|---|---|---|---|---|---|
| 安置房（二类经适）不满二、不满五唯一 | 3.3% | 3% | 1% | 1% | **≈8.3%** |
| 安置房（二类经适）满二、不满五唯一 | 0 | 3% | 1% | 1% | **≈5%** |
| 安置房（二类经适）满五唯一 | 0 | 3% | 1% | 0 | **≈4%** |
| **三定三限已满5年（满五唯一）** | 0 | 0 | 1% | 0 | **≈1%** |
| 商品房满二满五唯一 | 0 | 0 | 1% | 0 | **≈1%** |
| 商品房满二不满五唯一 | 0 | 0 | 1% | 1% | **≈2%** |
| 商品房不满二 | 3.3% | 0 | 1% | 1% | **≈5.3%** |

## 二、预算反推公式

```
裸价上限 = 含税预算上限 ÷ (1 + 合计系数)
例：含税215万买"安置房满五唯一(4%)" → 裸价上限 = 215/1.04 ≈ 206.7万
例：含税215万买"安置房不满二(8.3%)" → 裸价上限 = 215/1.083 ≈ 198.5万
```

## 三、比价纪律

- 所有候选统一用**含税总支出**排序（除非用户指定 `tax_inclusive: false`）
- 每行标注适用的系数档位与前提（满二/满五唯一状态来自房源标签，现场以契税票复核）
- 中介报价默认为**裸价**；"XX万起可成交"类广告话术不作数，以具体挂牌房源为准
