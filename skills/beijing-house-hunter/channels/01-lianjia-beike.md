# 渠道 01：链家/贝壳 房源快照法

enabled: true
适用：所有二手房类型（商品房、安置房、回迁转商）——**主力渠道**

## 方法（直连有验证码，必须走搜索快照路径）

1. **小区页行情**：WebSearch 搜 `"{小区名}" 链家 二手房 房价`，抓快照中的：
   - 参考均价（元/㎡）、在售套数、建成年代、**交易权属**（商品房/一类经适/二类经适/定向安置房/三定三限——产权判定第一依据）
   - 小区页 URL 格式：`bj.lianjia.com/xiaoqu/{id}`（记录 id 供复查）
2. **户型行情（官方口径）**：快照中的格式化行 `3居室·77㎡·在售158万起`——这是链家按户型汇总的在售门槛，可信度高于转述
3. **具体房源**：搜 `"{小区名}" 链家 房源 2室 万`，要求快照含：面积、朝向、楼层、总价、满X状态。移动端房源页 URL 格式：`m.lianjia.com/bj/ershoufang/{id}.html`
4. **成交参考**：搜 `"{小区名}" 成交 万 链家`（成交价通常低于挂牌 3–8%）

## 证据标准

- ✅ 具体房源行（面积+价格+标签）或链家官方户型行情行
- ⚠️ 仅小区参考均价 → 进"待核实"区
- 直接 webReader 抓 bj.lianjia.com / m.ke.com 会命中 CAPTCHA，不要浪费时间重试，改用搜索快照
