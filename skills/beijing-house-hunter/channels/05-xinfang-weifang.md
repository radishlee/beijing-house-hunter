# 渠道 05：新房/现房/尾房/工抵房

enabled: true
适用：`house_types` 含"新房现房"或预算允许新房时跑

## 方法

1. 房天下新房：`newhouse.fang.com` 搜项目名（含参考均价+报价日期+价格有效期）
2. 吉屋网：`bj.jiwu.com`（总价区间口径，"XX万起"）
3. 清盘/工抵搜索：`{区域} 工抵房 清盘 特价 {年份}`、`{项目名} 现房 总价 起`
4. 开发商资质核查：企查查/新闻检索开发商近况（暴雷房企项目一律排除，如恒大系）

## 证据标准与要点

- 新房报价 = 渠道口径区间（网易推广页/吉屋/售楼处），**一房一价以售楼处为准**，输出时必注"需售楼处确认"
- 转售二手（新房交付后业主转卖）常低于开发商报价——同时跑渠道01查该项目二手挂牌
- 交易安全三件套：与开发商直签（非施工方/中介）、房款进预售资金监管账户、核网签备案状态
- 现房优势标签：即买即住、仅契税1%；"好房子"新规产品（2025.5后，层高3米/得房率85%+）对老批次次新有代差优势
