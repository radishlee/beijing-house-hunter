# 渠道 07：房天下租房站直爬（租金数据）

enabled: true
适用：需要小区/板块**租金**数据时（租售比计算、地段购买力验证）。搜索引擎限额时的替代通道。

## 已验证的爬取方法（2026-09-20 实测通过）
1. 商圈列表页服务端渲染、无验证码、gzip：`https://zu.fang.com/bj/house-a{区}-b{商圈}/`
   实测代码：新宫=a06-b017404、和义=a06-b02681、东高地=a0585-b02683
2. 找商圈代码：抓任意商圈页，正则 `href="(/bj/house-[^"]+)"[^>]*>([^<]{2,12})<` 提取同区其他商圈导航
3. 数据以嵌入JSON存在：正则 `"([^"]{2,20})\s(\d)室(\d)厅\s([\d.]+)㎡\s(\d{4,5})元/月"` → (小区,户型,面积,租金)
4. 请求要求：浏览器UA + `Accept-Encoding: gzip`（需手动解压）+ 每请求间隔≥1s
5. 触发滑块验证的条件：POST搜索接口 /bj/rentsearchnew/postservice/searchbox/ 或高频请求——用商圈URL直达可避开

## 已知边界
- 跨区商圈代码不在同页导航（新宫页看不到大兴瀛海）——需先拿到对应区/商圈代码
- 口径=房天下在租挂牌（非成交），样本量小（商圈仅4-14条），只做区间判断
- POST搜索接口必触发滑块，禁用
