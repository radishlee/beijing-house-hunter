# 渠道 02：安居客/房天下/幸福里 交叉验证

enabled: true
适用：对渠道01的结果做交叉验证；发现链家未覆盖的小楼盘

## 方法

1. 安居客小区页：`beijing.anjuke.com/community/view/{id}`、房价页 `mobile.anjuke.com/fangjia/...`（板块月度均价走势有用）
2. 房天下：`m.fang.com` 搜小区名；查房价走势 `fangjia.fang.com/zoushi/...`
3. 幸福里房源页：`i.99hdf.com/ershoufang/...`（房源级，含挂牌日期——**挂牌超6个月未售=割肉盘信号**）
4. 交叉规则：同一房源两源报价取区间表述（如"210万/216万"）；单源孤证标 ⚠️

## 已知污染（详见 references/blacklist.md）

- 房天下页面级均值 bug：`54,429元/㎡` 在多个无关小区复现——凡引此口径一律作废
- 58同城可能把安置房标注为"小产权"（与政府大红本公示矛盾时以官方为准，标 ⚠️）
- 安居客部分板块同比数据与其他源矛盾时弃用
