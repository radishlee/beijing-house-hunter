# 渠道 03：政府不动产登记公示（安置房下本核心渠道）

enabled: true
适用：`house_types` 含定向安置房/回迁房时**必跑**；追踪"近几年新下本"

## 方法

1. **规自委分局公告列表页**（webReader 直抓，不走搜索）：
   `https://ghzrzyw.beijing.gov.cn/zhengwuxinxi/tzgg/{区代码}/`
   区代码：ft=丰台、dx=大兴、cy=朝阳、hd=海淀、sjs=石景山、tzg=通州、fs=房山、cp=昌平、sy=顺义、mtg=门头沟
2. 在公告列表中检索关键词：`遗登`（历史遗留登记公示，如"2025丰遗登02号"）、`安置`、`回迁`、`首次登记`、`颁证`
3. 公告正文给出：楼栋号、套数、产权单位、公示日期——用于判定"下本时间线"（首次登记公示 → 个人分户本通常滞后 6–12 个月）
4. 区政府官网（如 bjft.gov.cn）新闻检索：`安置房 交付`、`大红本`、`不动产权证 发放`

## 证据标准

- ✅ 公告原文（编号+日期+楼栋清单）
- 人民网领导留言板答复（liuyan.people.com.cn）作为"办证进度"辅助证据
- 注意：**首次登记≠分户下本**，可交易以业主个人不动产权证为准（输出时必注）
